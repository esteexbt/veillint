ENGINE NOTES

What this tool
can and can't see.

VeilLint is an early-stage static heuristic scanner. It is designed to surface review prompts, not certify a wallet or application.

01

Pattern-based detection

Rules search source text for known-risk signals such as secret logging, transparent-payment calls, potentially sensitive memos, and viewing-key handling.

02

Local-first by design

Source text is processed in the current browser tab. This build does not send code to a server or require an account.

03

Not a privacy proof

Static matches can be false positives or miss indirect flows. The scanner does not execute code, inspect dependencies, capture network traffic, or verify cryptography.

04

Threat-model the whole path

Consider chain visibility, RPC providers, timing, IP address exposure, telemetry, analytics, error reports, key storage, backups, and the user's device.
