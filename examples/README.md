# Demo fixtures

- `risky-payment-flow.ts` intentionally contains patterns that should trigger several VeilLint review prompts. It is fictional and must never be used to send a real transaction.
- `clean-payment-flow.ts` is a benign negative example intended to show that ordinary UI preferences and formatting code should not trigger the added secret-storage rule.

These fixtures are small demonstrations, not a representative benchmark of all Zcash application code.
